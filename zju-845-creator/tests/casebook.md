# 六个基准题型（仅供开发回归，答案默认不可面向考生展示）

这些案例均为原创或人工构造的基准，不可冒称浙江大学官方真题。

| 类型 | 改编数学结构 | 验算重点 |
|---|---|---|
| 时域 | 单位负反馈 K/[s(s+2a)]，峰值时间 π/3，峰值 1+e^-π | a=3,K=18，斜坡静差 1/3 |
| 根轨迹 | K(s+a)/[s(s+b)]，K=1/25 时各有二重根，a>b>0 | a=9,b=5；分离-3、汇合-15 |
| Nyquist | L=K(2s+1)/[s(s-2)]，K=2 | ω=1 负实轴交点 -2；K>1 稳定 |
| 离散 | L=K(z+1/2)/[z(z-1/2)] | Jury 稳定 0<K<2，K=2 临界 |
| 现代 | A=[[2,-1,-1],[-1,2,-1],[-1,-1,0]], B=[1,1,2]^T, C=B^T | AB=-B，传函 6/(s+1)，隐藏模态 2,3 |
| 指定答案 | A=[[-2,0,-1],[0,-2,3],[-1,3,1]],B=[3,1,0]^T | K=10,p=-2；隐藏不稳定模态 |

上表为回归用输入输出摘录，**不是**实证的全自动出题可靠性报告。
