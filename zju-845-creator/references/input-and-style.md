# 读取与命题风格规范

## 输入
文字、LaTeX、图片和 PDF 都可以作为原题，但图像/PDF 提取依赖宿主工具。数学公式保留括号、上下标、转置和矩阵顺序。对框图特别核对反馈正负号、求和点、交点是否真的连接、箭头方向；模糊时停止猜测。若上传多题，逐题改编。

## 来源
只依据实际读取的历年真题归纳风格；若没有实证材料，只能标注“浙大845风格的原创模拟题”，不得宣称官方预测。禁止将未经授权的完整考试资料直接打包进公开仓库。

## 输出
语言简洁、题干自足、公式使用 LaTeX、小问按逻辑递进，必要常数如 ln2 或 arctan2 可以在题末给近似，精度和角度单位必须一致。默认不公开内部演算和答案，不能用命题说明泄露关键突破口。
